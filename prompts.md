# Prompt 1

Build a React movie search application.

Requirements:
- Search movies using an API.
- Display movie posters, title, and release year.
- Allow users to add movies to favorites.
- Allow removing favorites.
- Use React Hooks.
- Use reusable components.
- Make the layout responsive.
- Explain the folder structure before generating code.

 – Clean the Vite Starter Project

Guide me step by step to remove the default Vite React demo code and prepare the project for a Movie Search application. Explain why each change is needed before showing how to make it.

# Prompt 2 – Build the Initial Application Layout

Help me build the initial layout for a Movie Search application using React and Vite. Explain each React element and CSS rule as if I am a beginner. Create a page with a title, search input, search button, and a placeholder section for displaying movies without implementing functionality yet.

# Prompt 3 – Connect the Search Input to React State

Teach me how to use React's useState hook to make the movie search input a controlled component. Explain what state is, why controlled inputs are important, and guide me step by step without implementing the TMDB API yet.

# Prompt 4 – Handle Search Events

Show me how to implement a reusable search handler in React that responds to both the Search button and the Enter key. Include basic validation to prevent empty searches, but do not connect the TMDB API yet.

# Prompt 5 – Connect the TMDB API

Help me connect my React + Vite Movie Search application to the TMDB API using the Fetch API and an environment variable for the API key. Display each movie's title, release date, and rating after a successful search.

# Prompt 6 – Create a Reusable MovieCard Component

Help me refactor my React Movie Search application by creating a reusable MovieCard component that displays each movie's poster, title, release date, rating, overview, and a placeholder Favorite button.

# Prompt 7 – Add Favorites with localStorage

Help me add a Favorites feature to my React Movie Search application. Users should be able to add and remove favorite movies, and the favorites should persist using localStorage.

# Prompt 8 – Improve User Experience

Help me improve my React Movie Search application by adding loading and error states while keeping the existing Favorites functionality. Display appropriate feedback during API requests and when errors occur.

# Prompt 9 – Improve the UI

Help me redesign my React Movie Search application with a modern dark theme, responsive layout, improved movie cards, and better button styling while keeping the existing functionality unchanged.

# Prompt 10 – Final Application Polish

Help me improve the final user experience of my React Movie Search application by adding clear empty states, no-results feedback, and small usability improvements without changing the existing core functionality.
