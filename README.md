# 🎬 Movie Search & Favorites

A modern Movie Search application built with **React** and **Vite** using the **TMDB API**.

## Features

* Search movies using the TMDB API
* View movie posters
* Display release dates and ratings
* Add and remove favorite movies
* Favorites saved using localStorage
* Responsive design
* Loading and error handling

## Technologies Used

* React
* Vite
* JavaScript (ES6+)
* CSS3
* TMDB API

## Installation

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file:

```env
VITE_TMDB_API_KEY=YOUR_API_KEY
```

4. Start the development server:

```bash
npm run dev
```
